# Discord AI
Have a anime girl DM you on Discord!

Completely written from scratch with no dependencies, no discord.js!!!!

## Features
* **OpenAI API** - Can use any LLM that uses the OpenAI API
* **ElevenLabs API** - Can talk to you in VC or as audio attachments in messages, using ElevenLabs API (it can't listen to you though)
* **Conversation starter** - Can start conversations at random
* **Read delay** - Can delay response to simulate reading your message
* **Realistic typing animation** - Shows a typing indicator like theres actually a UwU anime girl typing to you
* **Works anywhere** - Can talk in VC, text channels, group chats & DM's
* **Self bot???** - Can work as a self bot (user account instead of bot), your account can get disabled/suspended though
* **Memory** - Keeps memory of important stuff
* **Completely customizable** - You can change basically everything from config

## Requirements
* [Bun](https://bun.sh)
